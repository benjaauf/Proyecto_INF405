# Proyecto INF405 - Procesamiento de Señales e Imagenes

> Comparación de técnicas de análisis tiempo-frecuencia para la caracterización del ritmo alfa en señales EEG de ojos abiertos y cerrados

### Origen de los Datos
Los datos utilizados en este estudio provienen del repositorio **UCI Machine Learning**.
- **Dataset:** EEG Eye State Detection.
- **Licencia:** CC BY 4.0.

> Roesler, O. (2013). EEG Eye State [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C57G7J.
